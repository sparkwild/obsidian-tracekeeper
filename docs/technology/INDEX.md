# Technology Documentation

This category records accepted technical selections and the constraints that
make those choices appropriate for Tracekeeper.

## Belongs Here

- Languages, frameworks, protocols, storage forms, tooling, and compatibility policy
- Accepted selections and the rationale or constraints behind them

## Does Not Belong Here

- Module ownership, feature behavior, contributor procedures, or candidate comparisons
- Version-specific implementation status and evaluation evidence

- [TECHNOLOGY_STACK.md](TECHNOLOGY_STACK.md) — Accepted runtime, storage, protocol, UI, workspace, and release-tooling choices.
