# Feature Documentation

This category defines what Tracekeeper can do and the durable behavior of its
user and Agent workflows.

## Belongs Here

- Agent connection, Recall, tracked work, and source-ingestion workflows
- Knowledge governance, review, migration, diagnostics, and feature limits

## Does Not Belong Here

- Package ownership, runtime transport, trust-zone implementation, or build rules
- Dated implementation status, evaluation results, or one-off remediation plans

## Current Documents

- [AGENT_CONNECTION.md](AGENT_CONNECTION.md) — Agent setup, evidence states, client capabilities, and onboarding behavior.
- [AGENT_WORKFLOW.md](AGENT_WORKFLOW.md) — Normative Agent, Skill, and MCP workflow behavior.
- [KNOWLEDGE_GOVERNANCE.md](KNOWLEDGE_GOVERNANCE.md) — Knowledge maintenance, review, memory, graph, migration, and human-control behavior.
