# Architecture Documentation

This category defines Tracekeeper's system structure, runtime and data flow, and
technical trust boundaries.

## Belongs Here

- System topology, component ownership, dependency direction, and lifecycle
- Vault data flow, indexing, write coordination, authentication, and trust boundaries

## Does Not Belong Here

- User workflow copy, technology-selection rationale, contributor checklists, or status snapshots
- Task plans, review findings, and release progress
